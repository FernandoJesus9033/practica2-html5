## Conclusiones

### 1. Aprendizaje de HTML5
Se aprendió a usar correctamente las etiquetas semánticas de HTML5:
- `<header>` para el encabezado
- `<nav>` para la navegación
- `<section>` para las secciones
- `<article>` para los artículos
- `<footer>` para el pie de página

### 2. Uso de Listas
Se practicó el uso de:
- **Listas ordenadas** (`<ol>`) para las características detalladas
- **Listas no ordenadas** (`<ul>`) para los menús y herramientas

### 3. Títulos y Párrafos
Se usaron correctamente:
- **Títulos:** `<h1>`, `<h2>`, `<h3>` para jerarquizar el contenido
- **Párrafos:** `<p>` para el contenido textual

### 4. Control de Versiones con GitHub
Se aprendió a:
- Crear un repositorio público en GitHub
- Sincronizar una carpeta local con el repositorio remoto
- Usar comandos `git add`, `git commit`, `git push`
- Publicar el plan en `README.md`

### 5. Registro de Tiempos con TopTracker
Se aprendió a:
- Crear un proyecto en TopTracker
- Registrar el tiempo de trabajo
- Comparar el tiempo estimado con el real

### 6. Diferencia de Tiempos
El tiempo real (13 min) fue **mucho menor** al estimado (3.5 horas) porque:
- No se aplicaron estilos CSS (eso será en la Práctica 3)
- La estructura HTML fue más rápida de lo esperado
- Se reutilizó código entre las dos páginas

### 7. Publicación en el Sistema de la Práctica 1
Se publicaron las páginas HTML en el servidor Apache de la Práctica 1:
- `http://localhost/index.html`
- `http://localhost/caracteristicas.html`
